Semplice tool per ESP32-C3 SuperMini con architettura Risc-V volto ad
agevolare l’apprendimento dell’architettura stessa. Il sistema permette la scrittura,
compilazione ed esecuzione di codice Assembly direttamente sul microcontrollore. Il
software offre varie modalità di utilizzo ed è utile per validare vari tipi di esercizi,
concepiti per supportare chiunque desideri approcciare lo studio di RISC-V.
